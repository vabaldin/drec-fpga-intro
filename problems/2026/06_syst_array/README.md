## Задание

* Добавить AXI-Lite slave-интерфейс для доступа к управлению систолическим массивом

| Смещение | Регистр |
|---|---|
| `0x00` | Запись `1` запускает загрузку B, запись `2` запускает A × B. |
| `0x04` | Статус: биты 0–3 — `busy`, `done`, `error`, `b_loaded`. Новый запуск сбрасывает `done`. |
| `0x08`, `0x0c`, `0x10` | 32-битные адреса A, B и C. |

Адреса и формат памяти описаны в задании 05. `make test` проверяет регистры,
байтовые маски, AXI-Lite ответы и запуск умножения.
