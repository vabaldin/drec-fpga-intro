## Задание

* На основе модуля `axil2reg` сделать свой аналог AXI GPIO
* Проверить его работоспособность в системе c ZYNQ PS и 4 светодиодами под управлением Linux

`make bitstream` собирает проект Zynq и экспортирует
`fpga/design_1_wrapper.xsa`. Для загрузки Linux используйте этот XSA
с [примером 09](../../../examples/2026/09_ps7_axi_led). Регистр данных по адресу
`0x43c00000` хранит четыре младших бита, управляющих светодиодами.

`make test` проверяет регистр AXI-Lite в симуляторе. На плате выполните
`sh test-led.sh` от root и проверьте, что загораются светодиоды по шаблонам.
