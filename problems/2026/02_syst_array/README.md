## Задание

1. Processing Element, параметризованный разрядностью операндов (WIDTH=16)
2. Систолический массив, параметризованный размером (SIZE=4) и разрядностью
3. Сдвиговый регистр с valid-интерфейсами, параметризованный разрядностью
4. Систолический массив (WIDTH=16, SIZE=4) со сдвиговыми регистрами
5. Тестбенч для систолического массива, проверяющий умножение матриц m,n,k=4,4,4
6. Систолический массив c поддержкой Idle по A и B матрицам

## Интерфейс `sa_top`

- Положительные параметры `SIZE` и `WIDTH` задают размер квадратных матриц и разрядность беззнаковых операндов. По умолчанию `SIZE=4`, `WIDTH=16`.
- На такте с `i_a_valid=1` передаётся очередной столбец A, а с `i_b_valid=1` — очередная строка B. Обе последовательности идут в порядке возрастания индекса `k` от 0 до `SIZE-1`. Элемент с индексом `j` занимает биты `[j*WIDTH +: WIDTH]`.
- Входы принимаются независимо. При `valid=0` соответствующая последовательность приостанавливается. Массив объединяет принятые столбцы и строки по индексу и подаёт их в вычислительную сетку через линии задержки.
- После приёма `SIZE` векторов с каждого входа результат готов через `2*SIZE-1` тактов. `o_valid` и матрица `o_c` удерживаются до сброса. Элемент `C[row][col]` занимает биты `[(row*SIZE+col)*ACC_WIDTH +: ACC_WIDTH]`, где `ACC_WIDTH = 2*WIDTH + $clog2(SIZE)`.
- Синхронный сброс (`rst_n=0` или `clear=1`) очищает результат и текущую операцию. Для следующего умножения подайте `clear` на один такт. На такте сброса входные векторы не принимаются.

## Проверка

`make verilator` или `make iverilog` запускает самопроверяющийся тестбенч и записывает `dump.vcd`. Тесты проверяют результаты умножения, независимые паузы на обоих входах, сброс и предельные значения операндов. `make lint` проверяет RTL в Verilator.
