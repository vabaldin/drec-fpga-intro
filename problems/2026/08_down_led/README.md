## Задание

* Установить Vivado 2025.1
* Запустить на плате счетчик с выводом на LED
* Написать счетчик обратного счета с выводом на LED и запустить его на плате 
Для прямого счёта соберите проект `examples/2026/08_led` командой
`make project` и сгенерируйте bitstream в Vivado. Для обратного счёта выполните
`make bitstream` в этой папке. В Vivado Hardware Manager загрузите на плату
`fpga/fpga.runs/impl_1/fpga_top.bit`. Старшие четыре бита счётчика
выведены на светодиоды. `make test` проверяет обратный счёт, переход через
ноль и асинхронный сброс.
