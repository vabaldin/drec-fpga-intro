## Задание

1. Интегрировать ускоритель матричного умножения в Zynq-7000 SoC
2. Разработать драйвер, позволяющий пользовательскому приложению умножать матрицы при помощи ускорителя

`make bitstream` создаёт проект Zynq-7000, подключая регистры по GP0 по адресу
`0x43c00000` и доступ к DDR через HP0. Для загрузочного образа по схеме
[примера 09](../../../examples/2026/09_ps7_axi_led) используйте
`fpga/design_1_wrapper.xsa` и `fpga/fpga.runs/impl_1/design_1_wrapper.bit`
из этого проекта.
Добавьте узел из `sa-overlay.dts` в загрузочное дерево устройств. Если узел
по этому адресу уже есть, задайте ему `compatible = "drec,systolic-array"`.

Соберите драйвер и программу командой `make KDIR=/путь/к/сборке/ядра`.
На плате выполните `insmod drec_sa.ko` и `./sa_test` от root.
Приложение передаёт две матрицы 4×4 через `SA_MULTIPLY` на `/dev/drec-sa`
и получает результат в той же структуре. Драйвер использует когерентные
DMA-буферы. `make test` проверяет верхний RTL и прогоняет тестбенчи AXI.
