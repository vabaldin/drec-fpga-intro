## Задание

* Сделать для QEMU модель устройства mul-dev с 3 регистрами, доступными через MMIO
* Запись в 2 регистра сохраняет множители, чтение из 3-го регистра возвращает результат умножения
* Добавить устройство в ARM-машину virt
* Проверить работу устройства с помощью bare-metal программы на C

Примените `mul-dev.patch` к исходникам QEMU 9.2.4 командой
`patch -p1 -i /путь/к/mul-dev.patch`. Соберите `arm-softmmu` по руководству
[QEMU](../../../docs/2026/07_qemu.md). Затем запустите
`make test QEMU=/путь/к/qemu-system-arm`.

Адреса 32-битных регистров: `0x09008000` (A), `0x09008004` (B),
`0x09008008` (младшие 32 бита произведения, только чтение).
