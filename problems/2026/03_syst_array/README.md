## Задание

Систолический массив с поддержкой valid/ready flow control (с помощью FIFO и credit counters)

`sa_stream` использует порядок векторов из задания 02. На каждом входе вектор
принимается при `valid && ready`. Пары подаются в массив по порядку, а кредит
резервирует место в FIFO результатов до запуска умножения. Кредит возвращается
при чтении результата. `make lint` проверяет RTL. Тест находится в задании 04.
